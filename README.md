## requirement
- android 11+
- camera2 compatible
## status
**project is still in beta dont expect much**
**app just works it isn't aesthetic yet**
### Working
- [x] Front/rear cameras
- [x] HTC GLES photo processing
- [x] 9 effects from the htc
- [x] Upright, letterboxed preview
- [x] Tap-to-focus, sensor AF and face AF
- [x] Effect-based focus gating

### Incomplete / Not Working
- [ ] Depth of Field, Fisheye, Dots and Tilt-shift
- [ ] Auto-enhance (NR/LightBoost unverified)
- [ ] HTC ISP and color science
- [ ] HTC video processing
- [ ] Lens selection
